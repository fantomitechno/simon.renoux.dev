fantomitechno's infrastructure

So I run my own services like this website and others! Let's discuss this! The configuration for all of this can be found in my dotfiles

Basis

My homelab is built inside my appartment, I own 2 servers, 2 switchs and a router:

  • Conseil (NAS Server): HP HPE DL60 Gen9 (CPU: Xeon E7-8890 v3, RAM: DDR3 16G, SSD: -, HDD: 2x14T Seagate Exos X16, 4x 10G SFP+)
  • fant0mib0t (Compute server): HP HPE DL60 Gen9 (CPU: 2x Xeon E7-8890 v3, RAM: DDR3 32G, SSD: -, 4x 10G SFP+)
  • OpnSense-DeLoreane (Router): HP T620 Plus Thin Client (CPU: AMD GX-420CA, RAM: DDR3 4G, SSD: 16GB?, 2x 10G SFP+)
  • CRS309-PortalGun (Core Switch): Mikrotik Switch Cloud CRS309-1G-8S+IN (8x 10G SFP+)
  • SG500X-Argo3 (User Switch): Cisco SG250-18-K9 (18x 1G Ethernet, 2 1G SFP)

In France, it is not really frequent to not use your ISP's router... yeah, anyway, I am using my own lmao. For now, my ISP is Bouygues Telecomes. But plan is to change for FAImaison. (associative ISP I am a member of)

Network configuration

So first, I wanted to use something I don't see often, there is 3 ranges of privates IPs: 192.168.0.0/16, 10.0.0.0/8 and 172.16.0.0/12. I do not see much of the third range being used in the networks I worked in (for organisations: a lot of 10/8 because of its enormous range of devices allowed 16,777,214, and for residential networks: 192.168/16). My network is then 172.16.0.0/16 (I am skipping 4 bits, to allow me to experiment with dn42 in the futur)

Along this choice of network, I have 4 subnets with VLANs:

  • The ADMIN network at 172.16.10.0/24 using VLAN 10, accessible via 802.1X authentificated Ethernet.
  • The ADMIN VPN network at 172.16.15.0/24 using VLAN 15, accessible via Wireguard.
  • The SERVERS network at 172.16.20.0/24 using VLAN 20, accessed with specific SFP+ ports on the Core Switch.
  • The GUEST network at 172.16.100.0/24 using VLAN 100, accessed via Wi-Fi and unauthentified Ethernet.

The different hardwares I own are accessible to the following IP addresses:

  • OpnSense-DeLoreane: this device is accessible on all networks, 172.16.10.1, 172.16.15.1, 172.16.20.1 and 172.16.100.1
  • CRS309-PortalGun: 172.16.20.2
  • Conseil: 172.16.20.10
  • fant0mib0t: 172.16.20.20
  • SG500X-Argo3: 172.16.20.3

They are connected as follow:

The router is running OpnSense. All other servers are running NixOS and the switchs are running the latest (accessible) version of their software.

Port 80 and 443 of fant0mib0t are forwarded from OpnSense-DeLoreane to the Internet allowing my public IP to host my services. Every services is also hosted on the local network of each machine, not even allowing access without going through the reverse proxy (I use Caddy btw)
